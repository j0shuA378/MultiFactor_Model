纯 Python 命令行独立运行指南

您也可以随时在终端直接运行独立的纯 Python 量化回测框架，支持一键生成 ANSI 彩色绩效报表与导出 JSON：

python backtest_cli.py --ticker NVDA --strategy all --period 2y

可用命令行参数：

  • --ticker <SYMBOL>: 股票代码（如 AAPL, NVDA, TSLA, SPY, QQQ）
  • --strategy <momentum|ml|turtle|all>: 策略类型或三大策略同时对比
  • --period <6mo|1y|2y|3y|5y>: 回测历史周期跨度
  • --capital <FLOAT>: 初始回测账户本金
  • --export <PATH.json>: 自动将回测结果导出为 JSON 文件
